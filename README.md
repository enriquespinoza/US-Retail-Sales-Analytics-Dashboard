# U.S. Retail Sales Analytics Dashboard

## Overview

This project analyzes U.S. Census Bureau Monthly State Retail Sales data using SQL, Python, Excel, and Power BI to identify geographic and industry trends.

## Business Problem

Retail executives need a dashboard to monitor state performance, compare retail sectors, and identify growth opportunities.

## Technologies

- Power BI
- SQL
- Python
- Excel
- GitHub

## Data Source

- U.S. Census Bureau Monthly State Retail Sales
- Standard Errors
- Coverage Measures
